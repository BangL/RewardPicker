# Reward Picker

RAID: World War II mod (SuperBLT). Test helper for the mission end reward.

## Options (BLT options menu)

- **Mission end reward:** `Vanilla` (default), `Ask`, or force one type: weapon skin (only not yet owned
  ones, including SkinLib skins), customization, melee weapon, XP, gold bars, card pack. If nothing of that
  type is left to drop, the normal drop is used.
- **Ask:** a popup on the loot screen lets you pick the type live. Types with nothing left to drop are not
  offered. `Random (vanilla)` is the normal drop, and so is ESC.
- **Live choice timeout:** seconds without mouse movement or arrow keys until the popup picks
  `Random (vanilla)`. `0` = never.
- **Rarity:** `Any` / common / uncommon / rare, for weapon skins and customizations.

Only affects your own drop; other players are not involved.
